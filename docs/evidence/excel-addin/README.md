### บั๊กที่พบระหว่างทดสอบ

ในหน้าต่างที่สูงไม่พอ ตารางการเชื่อมต่อหายไปทั้งตาราง (สูง 0 px) แม้ข้อมูลอยู่ในหน้า
สาเหตุ: `.cbody` สูงคงที่และเลื่อนได้ หน้านี้ใช้ `grid` ซึ่งบีบการ์ดที่เป็น `overflow-hidden`
จนเหลือ 0 แก้เป็น `space-y-4` แบบหน้าอื่น วัดใหม่ได้ 89 px

## ยังไม่ได้ทดสอบ

- ติดตั้งไฟล์ที่ดาวน์โหลดจากเว็บใน Excel จนเห็นแท็บ CMAS (ข้อ S1, S2 ใน `app/excel-addin/README.md`)
- ซิงก์คะแนนสองทาง, ช่องสีแดง, ออฟไลน์ (S4–S13)
- ทุกอย่างบน Mac
