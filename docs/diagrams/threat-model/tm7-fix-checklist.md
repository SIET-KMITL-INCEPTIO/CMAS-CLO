## 6. Trust boundary

รายงานรุ่น 2 ไม่มี boundary เลย จึงไม่มี threat หมวด Repudiation และไม่มี threat ของข้อมูลที่ข้ามเครือข่าย
ใช้ stencil *Generic Trust Line Boundary* (เส้น) หรือ *Generic Trust Border Boundary* (กรอบ) · **เส้นข้อมูลต้องตัดผ่าน boundary** ถึงจะนับ

- [ ] **Internet** (เส้น): คั่นระหว่าง `ผู้สอน` `ผู้ดูแลระบบ` กับ process ทุกตัว · ทุก Layer
- [ ] **Google** (กรอบ): ครอบ `Google บริการยืนยันตัวตน` · Layer0 และ Layer1
- [ ] **Supabase PostgreSQL** (กรอบ): ครอบ data store D1–D6 · Layer1 และ Layer2
