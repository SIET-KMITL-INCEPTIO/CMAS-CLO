# architecture/

Hand-drawn drafts of the software architecture and per-use-case flowcharts.
None of them is generated by a script under `scripts/`, so
`scripts/check-diagrams.py` does not regenerate or compare them. None has an
older or newer copy: they are siblings, not versions (see
[`docs/VERSIONS.md`](../../../VERSIONS.md) §3.6).

Moved here from `docs/uml/index-q/superseded/` on 2026-09-28. That folder is
for older copies, and these files have no newer copy.

| File | Status | What it is |
|---|---|---|
| `CMAS-Architecture_Handwritten.drawio` | draft | Software architecture of the code at commit `ff6ed7c` (2026-09-24), 8 pages: stack-and-flow overview in the style of the team slide (numbered steps ①–⑩, library icons loaded from the jsDelivr CDN so they need a network connection to show), 3-tier overview, client data flow, server request pipeline, Google-login sequence, admin-approve sequence, data layer and trust boundaries, and a tool-level sequence (Fastify / jose / Zod / Prisma / Postgres) for `GET /users`. Not generated by a script under `scripts/`, so `check-diagrams.py` does not regenerate or compare it. Redraw it once the `courses` / `clos` / `excel` / `dashboard` modules exist. |
| `CMAS-FE-BE-DB_Handwritten.drawio` | draft | One page, Frontend → Backend → Database, walking one request (ADMIN approves a user, `PATCH /users/:id/approve`) with steps ①–⑩ and the tool that handles each step (React, TanStack Query, Fastify, jose, Zod, Prisma, Postgres). Kept as its own file so it is not overwritten while `CMAS-Architecture_Handwritten.drawio` is open in draw.io. Same caveats as that file: not script-generated in `scripts/`, icons load from the jsDelivr CDN. |
| `CMAS-ARCH_Handwritten.drawio` | draft | One page titled "System Architecture": the stack in columns (React 19, TypeScript, Vite 7, Tailwind v4, React Router 7, TanStack Query, Zustand, sonner, recharts, xlsx) with the page → hook → API layers. Same subject as `CMAS-FE-BE-DB_Handwritten.drawio`, drawn without the numbered request walk. Added in the same commit (`7e6b3ce`), so git cannot tell which came first. Not script-generated. |
| `CMAS-Flowcharts_Handwritten.drawio` | draft | One flowchart per use case (49 pages, numbered as in `../../index-q/UML-INDEX-Q.drawio`) plus a contents page. The steps, conditions and error messages are read from the prototype `docs/pages/index-q.html` (e.g. `FORMS.*.validate`, `validateWorkbook`, `save-course`), not from `app/server`, which only implements auth and users so far. Generated from a script that is not yet in `scripts/`, so `check-diagrams.py` does not regenerate it. |
