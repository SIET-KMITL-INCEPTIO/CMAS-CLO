อ่านภาพนี้อย่างไร

PK คีย์หลัก (ขีดเส้นใต้) · FK คีย์นอก · UQ ค่าไม่ซ้ำ
เส้น — ขีดคู่ฝั่งตารางแม่ = ต้องมีหนึ่งแถว · ตีนกาฝั่งตารางลูก = ศูนย์ถึงหลายแถว · วงกลมกับขีด = ศูนย์หรือหนึ่งแถว

StudentGrade → Student เป็น 1:1 เพราะ studentId เป็น UNIQUE — หนึ่งการลงทะเบียนมีเกรดเดียว
AuthEvent มีเส้นไป User สองเส้น — userId คือบัญชีที่ถูกกระทำ actorId คือผู้กระทำ
คะแนน CLO ไปถึงผ่านจุดประสงค์ — Activity → AssessmentCriteria → BehavioralObjective → CLO (migration 0006)
Course คือราก — ไม่มีตารางใดอยู่เหนือรายวิชา (ตัด Curriculum/PLO ตามมติ 2.7)
พื้นเหลือง = [index-q] ต้นแบบเสนอเพิ่ม ยังไม่อยู่ใน schema.prisma — ตาราง UploadReject · AuthEvent · คอลัมน์ User.mustChangePassword · User.pwResetAt · User.pwChangedAt · ScoreUploadLog.kind
สิ่งที่ SQL บังคับไม่ได้ และอยู่ที่แอป

สิทธิ์ในรายวิชา — บทบาทเดียว ผู้สอนทุกคนของวิชาทำได้เท่ากัน (D1) จึงไม่มี CourseInstructor.role · ใครทำอะไรได้ตัดสินที่ rbac middleware (course-role-permissions.md)
