## 2 · เฟส (1 เฟส = 1 branch · จัดกลุ่มตาม contract)

### P1 · คำและลำดับ — ไม่มีอะไรอ่านผลผลิต (ทำได้ทันที ไม่ต้องรอมติ)
- F1 label `บรรยาย (ชม.)` `ปฏิบัติ (ชม.)` `ศึกษาเอง (ชม.)` + พรีวิว `3 (2-2-5)` มีคำอธิบาย "หน่วยกิต (บรรยาย-ปฏิบัติ-ศึกษาเอง ชม./สัปดาห์)" ทั้งฟอร์มและตารางรายวิชา
- F6 `คำอธิบาย CLO` → `CLO (ผลลัพธ์การเรียนรู้ระดับรายวิชา)` ทั้ง label และข้อความ validate
- F2 คำอธิบายเกรดข้างตัวเลือก: ตัวอักษร A–F = ขั้นบันไดคะแนน 8 ขั้น · ผ่าน/ไม่ผ่าน = S/U ตามเกณฑ์ผ่านรายวิชาเท่านั้น · อิงเกณฑ์ vs อิงกลุ่ม 1 บรรทัด
- F3 hint แยกสองคำ: "เกณฑ์ผ่าน CLO = คะแนนขั้นต่ำของนักศึกษา 1 คน" · "เกณฑ์ผ่านรายวิชา = คะแนนรวมขั้นต่ำ"
- F8 ใต้หัว "จุดประสงค์เชิงพฤติกรรม" ใส่คำอธิบายว่าจุดประสงค์แตกย่อยมาจาก CLO ข้อนั้น

**พิสูจน์:** เปิดฟอร์มสร้าง/ตั้งค่ารายวิชาและฟอร์ม CLO ใน browser อ่านข้อความได้ตรง · ไม่มี label เดิมหลงเหลือ (`grep "คำอธิบาย CLO"` = 0)

### P2 · ย้ายเกรดไปหลัง CLO — อ่านผลของ P1 (ข้อความเดียวกัน)
- ฟอร์ม "สร้างรายวิชา" เหลือ ข้อมูลวิชา + หน่วยกิต/ชม. + ผู้สอน · ย้าย `เกณฑ์เกรด / วิธีตัดเกรด / เกณฑ์ผ่านรายวิชา` ไปแท็บ "การตัดเกรด"
- ค่าเริ่มต้น LETTER / อิงเกณฑ์ / 60% ยังถูกบันทึกตอนสร้าง (schema ไม่เปลี่ยน) และแท็บการตัดเกรดแสดง checklist ขั้นตอน: CLO → จุดประสงค์ → วิธีประเมิน → เกณฑ์ → เกรด

**พิสูจน์:** สร้างวิชาใหม่ในฐานะผู้สอน → วิชาถูกสร้างได้โดยไม่เห็นช่องเกรด · แท็บการตัดเกรดตั้งค่าได้ · `check-perm-matrix.js` ผ่าน

**ผลที่วัดแล้ว (P1 + P2):**
- ฟอร์มรายวิชา: label `บรรยาย/ปฏิบัติ/ศึกษาเอง (ชม.)` · ไม่มี `f-scale` / `f-pass` แล้ว
- สร้างวิชาใหม่ → LETTER · อิงเกณฑ์ · 60% · ขั้นบันได 8 ขั้น · ไปหน้าภาพรวม
- `modalGrading` (ปุ่ม "ตั้งค่าการตัดเกรด", capability `band.write` = LEAD): บันทึกเกณฑ์ 55% ได้ · PASS_FAIL + อิงกลุ่ม ถูกปฏิเสธ (CR-10) · เปลี่ยนรูปแบบเกรดขณะมีเกรดตรึง ถูกปฏิเสธ · เปลี่ยนเป็น PASS_FAIL → ขั้นบันไดเหลือ S/U
- ฟอร์ม CLO: `CLO (ผลลัพธ์การเรียนรู้ระดับรายวิชา)` + hint เกณฑ์ผ่าน/เป้าหมาย · console ไม่มี error
- `check-action-caps` (เพิ่ม 2 กรณี) · `check-perm-matrix` · `check-auth-events` ผ่าน
