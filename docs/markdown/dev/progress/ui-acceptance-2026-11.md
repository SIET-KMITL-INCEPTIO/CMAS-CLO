## 3. ยังไม่ผ่าน / ยังไม่ได้ทำ

- **P2 ยังไม่ได้ทำ** — สถานะที่ขาดของหน้าแรก ภาพรวม และตัดเกรด · ข้อความ error ภาษาไทยทุกจุด (UI-3, UI-7)
- **ข้อจาก axe ที่ไม่ใช่สี** (baseline ของ P0): `label-content-name-mismatch` หน้าผู้ใช้ (ปุ่มหัวคอลัมน์ "ผู้ใช้ ▲" มี `aria-label` ไม่ตรงข้อความ) · `target-size` หน้ากิจกรรม · `scrollable-region-focusable` หน้าแรก ภาพรวม และตัดเกรดบนจอ 375 px
- **UI-1 และ UI-8 ทุกหน้า** ต้องเปิดคู่กับต้นแบบบน seed เดียวกันแล้วไล่ทีละหน้า — ยังไม่ได้ทำ
