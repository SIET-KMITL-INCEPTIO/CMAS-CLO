# ธีมมืด (Dark theme) สำหรับการทำงานต่อเนื่องนาน ๆ

ค่าสีอยู่ที่ `app/client/src/styles/tokens.css` (บล็อก `:root[data-theme="dark"]`)
และ `contrast.test.ts` ตรวจทุกคู่สีข้อความ/พื้นผิวให้ได้อย่างน้อย 4.5:1 (WCAG 2.2 AA 1.4.3)

## 1. งานวิจัยบอกอะไร

งานวิจัยยัง **ไม่ได้ยืนยัน** ว่าธีมมืดช่วยให้ตาล้าน้อยกว่าในการทำงานทั่วไป ผลออกมาแตกต่างกัน
ขึ้นกับแสงในห้อง ขนาดตัวอักษร และความคุ้นเคยของผู้ใช้

| งานวิจัย | ผลที่เกี่ยวข้อง |
| --- | --- |
| Piepenbrock, Mayr, Mund & Buchner (2013), _Ergonomics_ 56(7):1116–1124 | ตัวอักษรเข้มบนพื้นสว่าง (positive polarity) อ่านชัดกว่า และตรวจทานข้อความได้ดีกว่า ทั้งในคนอายุน้อยและสูงอายุ |
| Piepenbrock, Mayr & Buchner (2014), _Ergonomics_ 57(11) | ข้อได้เปรียบของพื้นสว่างเห็นชัดที่สุดเมื่อตัวอักษรเล็ก |
| Dobres, Chahine & Reimer (2017), _Applied Ergonomics_ 60:68–73 | ในห้องมืด ตัวอักษรบนพื้นสว่างอ่านได้เร็วกว่า เมื่อห้องสว่างขึ้นทุกเงื่อนไขอ่านได้ดีขึ้น |
| Xie และคณะ (2021), _IEEE Access_ | อ่านตอนกลางคืนด้วยจอความสว่างต่ำ ตัวชี้วัดทางตาเอนไปทางธีมมืด แต่ผู้ร่วมทดลองรายงานว่าล้าน้อยกว่าและชอบธีมสว่างมากกว่า |
| Fan, Xie, Dong & Wang (2024), _Sensors_ 24(11):3516 | บนพื้นดำ สีตัวอักษรและแสงในห้องมีผลต่อความล้าของตาอย่างมีนัยสำคัญ |
| IJERPH (2025) 22(4):609, ผู้ใช้แท็บเล็ต 30 คน | ความล้าของตาระหว่างสองธีมไม่ต่างกันอย่างมีนัยสำคัญ |

**สรุป:** ธีมมืดเป็นทางเลือกที่ถูกต้องเมื่อผู้ใช้ชอบหรือทำงานในที่แสงน้อย
แต่ไม่ควรอ้างว่าธีมมืด "ถนอมสายตา" กว่าเสมอ ระบบจึงยังให้เลือกธีมสว่างได้

## 2. หลักที่ใช้ออกแบบ

งานวิจัยและแนวทางของแพลตฟอร์มชี้สาเหตุที่ทำให้ธีมมืดอ่านยาก ธีมนี้ออกแบบเพื่อแก้แต่ละข้อ

1. **พื้นเทาเข้มเกือบเป็นกลาง ไม่ใช้ดำสนิท:** Material Design แนะนำพื้น `#121212` เพราะเงายังมองเห็นได้
   และตัวอักษรสว่างบนดำสนิทจะดูฟุ้ง (halation) โดยเฉพาะผู้มีสายตาเอียง ธีมนี้ใช้ `#111218`–`#1d1f29`
   ผสมสีแบรนด์ (คราม) เพียงเล็กน้อย เดิมใช้กรมท่าอิ่มสีกว่านี้ (`#1b2038`)
2. **ตัวอักษรขาวนวล ความต่างประมาณ 12:1 ไม่ใช่ 19:1:** ข้อความหลัก `#dcdee8` บนการ์ดได้ 12.2:1
   ซึ่งเกินระดับ AAA (7:1) แต่ไม่จัดจ้าเท่าขาวบนดำ ข้อความรองทุกระดับ (`ink2` → `faint`) ได้อย่างน้อย 4.5:1
   บนทุกพื้นผิว ส่วนธีมเดิมมีข้อความ `faint` ที่ต่ำกว่าเกณฑ์อยู่สามคู่
3. **สีเน้นลดความอิ่มตัว และใช้เท่าที่จำเป็น:** Material ระบุว่าสีอิ่มตัวบนพื้นมืดทำให้เกิดการสั่นทางสายตา
   สีสถานะ (ok / warn / bad / info) จึงเป็นโทนพาสเทล และปุ่มหลักใช้พื้นครามกลาง `#3a4270` กับตัวอักษร `#e8eaf4` (8:1)
   แทนปุ่มสีม่วงอ่อนสว่างที่ทำให้เกิดแสงจ้าเป็นจุดบนหน้าจอ
4. **บอกระดับชั้นด้วยความสว่างของพื้นผิว:** แถบด้านบนและแถบข้าง (`#111218`) มืดที่สุด ถัดมาคือพื้นเนื้อหา
   รายการด้านซ้าย การ์ด และ popover ตามลำดับ สิ่งที่อยู่ "ใกล้" ผู้ใช้จึงสว่างกว่า เหมือนที่ Material ใช้ elevation overlay
5. **ภาษาไทยไม่เว้นระยะตัวอักษร:** หัวตารางและป้ายตัวเล็กเคยใช้ `letter-spacing` ตามแบบภาษาอังกฤษ
   ซึ่งดึงสระและวรรณยุกต์ออกจากพยัญชนะ (ก ิ จ ก ร ร ม) ข้อความที่เป็น `:lang(th)` จึงตั้งค่าเป็น 0
   ข้อนี้สำคัญเป็นพิเศษในธีมมืด เพราะตัวอักษรเล็กบนพื้นมืดอ่านยากอยู่แล้ว (Piepenbrock 2014)

## 3. คำแนะนำสำหรับผู้ใช้

- ทำงานในห้องที่มีแสงพอสมควร งานวิจัยพบว่าแสงในห้องช่วยให้อ่านได้ดีขึ้นในทุกธีม (Dobres 2017; Fan 2024)
- ถ้าต้องตรวจตัวเลขหรือข้อความยาว ๆ ในห้องสว่าง ธีมสว่างอาจอ่านแม่นกว่า (Piepenbrock 2013)
- ใช้ธีมที่รู้สึกสบายตา ความชอบส่วนตัวมีผลต่อความล้าที่รู้สึก (Xie 2021)
