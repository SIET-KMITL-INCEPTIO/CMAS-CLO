# components/

**Shared UI only.** A component that one feature uses belongs in that feature's
folder (`features/clo/CloListItem.tsx`, `features/dashboard/CloBarChart.tsx`). It
moves here when a second feature needs it. See [features/README.md](../features/README.md).

```
components/
├── ui/          shadcn/ui primitives — added via `npx shadcn@latest add <name>`
└── layout/      AppShell, Sidebar, Topbar — used by every page
```

## Rules

- **Named exports**, not default. (`*.page.tsx` files are the one exception —
  `pages.config.ts` lazy-imports them, which requires a default export.)
- Props type declared directly above the component, suffixed `Props`.
- Conditional classes go through `cn()` from `@/lib/utils`, never string
  concatenation.
- Components **never fetch**. Call the feature's `useXxx` hook; the hook owns the
  TanStack Query call. `useEffect` for data fetching is a rejected pattern
  (dev.md §14).
- Don't hand-edit files in `ui/` — they are regenerated by the shadcn CLI.

## Example

```tsx
type CloListItemProps = {
  clo: CloWithObjectives
  onDelete: (id: string) => void
  className?: string
}

export function CloListItem({ clo, onDelete, className }: CloListItemProps) {
  return (
    <div className={cn("flex items-center gap-2 rounded-md border p-3", className)}>
      {clo.description}
    </div>
  )
}
```
